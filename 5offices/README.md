# Рабочий проект Сити-Центра

Статическая версия для GitHub Pages с шифрованием всего содержимого. В репозитории находятся только экран входа, программа расшифровки и зашифрованный контейнер `payload.json`.

Содержимое защищено AES-256-GCM. Ключ получается из пароля через PBKDF2-HMAC-SHA-256, 600 000 итераций и случайную соль. Пароль не входит в исходный код, HTML или контейнер. Весь рабочий сайт — включая шрифты, JavaScript и финансовые данные — зашифрован целиком.

Сам экран входа и контейнер публично доступны. Проект открывается в браузере после расшифровки. Общий пароль даёт доступ любому его владельцу; индивидуальных учётных записей и журнала входов нет. Пароль не отправляется на сервер. Программа не сохраняет пароль или расшифрованные данные в localStorage, sessionStorage, IndexedDB или cookie. Кнопка «Закрыть доступ» удаляет расшифрованную страницу из интерфейса.

Нужен современный браузер с Web Crypto и DecompressionStream, а также HTTPS. Данные — сохранённый срез исходной таблицы; автоматической синхронизации нет.

Для обновления используйте отдельную исходную рабочую копию и заново сформируйте зашифрованный контейнер. Открытые исходники и файл с паролем в этот репозиторий не добавляйте.
