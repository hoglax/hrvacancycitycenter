# Сити-Центр — сайт для кандидатов

Самостоятельный статический сайт компании в Воронеже. HTML, CSS, JavaScript, шрифты и изображения находятся в этом репозитории. Аккаунт ChatGPT не нужен для просмотра сайта.

Публикация: GitHub Pages, ветка `main`, корень репозитория.

Информация о компании подготовлена по официальному сайту https://сити-центр-воронеж.рф и данным компании о 51 партнёре-застройщике.

Кнопка отклика открывает черновик СМС на +7 906 670-17-54 с текстом из блока «Знакомство». Кандидат отправляет сообщение самостоятельно. На компьютере доступны текст сообщения и копирование; сайт не отправляет СМС через сервер. Для iOS и Android предусмотрены разные форматы SMS-ссылки.
